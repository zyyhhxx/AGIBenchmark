# Notebooks

26 self-contained Kaggle notebooks — one per benchmark. Each notebook inlines all benchmark code and data so it can run directly on the [Kaggle Community Benchmarks](https://www.kaggle.com/benchmarks) platform with no external dependencies (beyond the `kaggle-benchmarks` SDK).

## By Track

### Metacognition (9)
- `metacog_fok.ipynb` — Feeling-of-Knowing
- `metacog_jol.ipynb` — Judgment-of-Learning
- `metacog_calibration.ipynb` — Retrospective Calibration
- `metacog_error_detection.ipynb` — Error Detection
- `metacog_learning_monitoring.ipynb` — Learning Monitoring
- `metacog_control.ipynb` — Metacognitive Control
- `metacog_epistemic_revision.ipynb` — Epistemic Revision
- `metacog_epistemic_humility.ipynb` — Epistemic Humility
- `metacog_canary.ipynb` — Contamination Canary
