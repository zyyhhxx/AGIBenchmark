[IMPORTANT] #M-6: Scoring description is oversimplified and partially wrong
  Writeup states: "Primary metric per task is a composite of gamma correlation
  (resolution), Brier Skill Score (calibration + discrimination), and
  task-specific accuracy."
  
  Actual scoring varies dramatically by task:
    - Calibration: 0.50*extreme_accuracy^1.5 + 0.25*BSS + 0.25*uncertainty_awareness
    - FOK: 0.40*gamma_norm + 0.30*BSS + 0.30*AUC
    - JOL: 0.40*gamma_norm + 0.30*BSS + 0.30*recall_rate
    - Control: 0.35*selection_relevance + 0.35*strategic_gain + 0.30*accuracy (no gamma, no BSS)
    - Epistemic Humility: 0.35*detection + 0.25*(1-confabulation) + ... (no gamma, no BSS)
    - Error Detection: 0.35*F1 + 0.25*localization + ... (no gamma, no BSS)
    - Canary: max(0, BSS) only (no gamma)
    - Epistemic Revision: 0.10*violation + 0.10*revision + ... (no gamma)
    - Learning Monitoring: 0.30*gamma + 0.30*accuracy + ...
  
  Only FOK, JOL, and Learning Monitoring actually use gamma. Claiming it's a
  blanket formula is misleading.

[MINOR] #M-7: Calibration scoring description doesn't match code
